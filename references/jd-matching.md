# JD匹配打分规则
> 用于AI销售岗位，自动分析JD，输出匹配分、优势、风险、投递建议

## 打分维度（总分100）
1. 岗位赛道匹配（30分）
- AI销售 / AI工具商务 / 大模型方案销售：25-30
- 跨境电商、AI自媒体、产品助理：15-24
- 传统实物销售、纯电销：0-10

2. 能力匹配（35分）
- 需要和客户沟通、方案讲解、B端对接：+15
- 需要懂AI提示词、AI工具、AI内容：+12
- 需要电商、流量、转化相关经验：+8
- 需要工程、图纸、项目落地经验：+5
- 要求多年成熟销售业绩、成熟客户资源：倒扣15

3. 硬性门槛（20分）
- 学历要求本科及以上：扣10分
- 要求3年以上销售全职经验：扣10分
- 地点广州/可远程：满分；异地不接受远程：扣20

4. 岗位避雷项（最多扣25分）
- 高频电话电销、陌拜扫街：-15
- 无边界加班、长期夜班：-10
- 催收、金融理财、灰产相关：-25（直接不推荐投递）

## 评级标准
- ≥80：⭐⭐⭐⭐⭐ 优先投递，重点冲
- 60~79：⭐⭐⭐⭐ 可以投递，优化话术
- 40~59：⭐⭐⭐ 谨慎投递，扬长避短
- ＜40：⭐⭐ 不建议投递

## 输出格式要求
1. 匹配分数+评级
2. ✅ 匹配亮点（结合候选人档案）
3. ⚠️ 短板风险点
4. 📝 投递策略：要不要投、简历侧重点、面试准备方向
5. 批量JD模式：多个JD一起对比，按分数排序，标注优先级
